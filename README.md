Project Title

To-Do List Web Application

Project Description (Resume Version)

Developed a responsive To-Do List Web Application using Python (Flask), HTML, and CSS that enables users to add and remove daily tasks through a simple and user-friendly interface. The application features a clean card-based design, responsive layout, and modern gradient styling to enhance the user experience. Flask handles the backend routing and task management, while HTML and CSS provide an intuitive and visually appealing frontend.

Detailed Project Description

The To-Do List Web Application is designed to help users organize their daily activities efficiently. Users can create new tasks, view the task list, and remove completed tasks through a straightforward web interface. The backend is developed using the Flask framework, which manages HTTP requests, routes, and task operations. The frontend is built with HTML5 and CSS3, featuring a responsive layout, Google Fonts integration, Flexbox, and gradient backgrounds for a modern appearance. Currently, tasks are stored temporarily in memory during runtime, making the application lightweight and suitable for learning Flask fundamentals.
